# Contributing

Tariffia Wallet is an independent fork in active pre-release development. The contribution and review process is not finalized yet.

Until it is, please coordinate before starting significant work. Small fixes, build improvements, and documentation corrections are welcome through a pull request.

- Do not include credentials, API keys, signing keys, or production configuration in a contribution.
- Preserve the upstream MIT license and the attribution in [NOTICE](NOTICE).
- Report security issues privately through the repository's GitHub Security tab instead of a public issue.
- Add or update tests where practical and describe what was verified.
